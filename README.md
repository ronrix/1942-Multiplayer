# 1942 Multiplayer Game
This is a simple game written in express and socket.io

## Usage | Features
- you can input your gamer name
- you can play with two or more players
- this game also has a chat feature, everyone can in the game can send a message

## Install and Run the game
- clone the repo `https://github.com/ronrix/1942-Multiplayer.git`
- run this command `npm install`
- to run the game simply run `npm start`
